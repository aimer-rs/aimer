# 26.0.0-dev.2

Changes since `26.0.0-dev.1`.

## New Features

### Media

- **Audio** playback on macOS and iOS, with Android, Windows, Linux and web backends. Remote audio streams while it downloads, and the seek bar is draggable.
- **Video** playback with zero-copy frames on macOS and iOS, plus backends for Windows (MediaPlayer frames as shared D3D textures) and web (copied from an `HTMLVideoElement`).
    - Linux and Android not have been finished yet
- A standard **video player** widget with captions, chapters and fullscreen.
- **GIF** support in assets.
- **Lottie** animation support.
- **Haptic feedback** for macOS and Android.

### Graphics and shaders

- Public **shader effects**, a **shader transpiler**, and a `ShaderEffectDecoration`.
- `CustomPaint` for drawing directly on a canvas.
- `bulge_radius` and bevel width options on `Magnification`.

### Layout and widgets

- `Center`, a lightweight widget for centering a single child.
- **Reverse mode** for `Scrollable`, for end-anchored content such as chat.
- Drag-to-scroll on the scroll track and thumb.
- **Accessibility** support.
- **Hinge and fold** support on iOS.
- `.px()` and `.pc()` sugar on numbers.

### Venus

- Added `spawn`: spawns a `!Send` future as a microtask that runs before the next build phase.
- Added `join!`: polls several futures together inside the awaiting task and returns all outputs as a tuple. Nothing is spawned or boxed per future.
- Added `join_all`: does the same for a collection of futures and returns the results in input order, not finishing order.
- Added `JoinHandle`: an owned handle to a spawned task. Dropping it cancels the task.
- Added `oneshot`, `mpsc`, `watch`: single-threaded channels for passing values between tasks.
- Added `Notify`, `Semaphore`: wake-up and permit primitives for coordinating tasks.
- Added `OnceCell`, `Shared`: compute a value once, or share one future's result between many awaiters.
- Added `Stream`, `StreamExt`: a minimal stream trait with combinators.
- Added `Latest`: keeps only the newest result of overlapping async work.
- Added `retry`, `retry_when`, `Backoff`: retry a failing future with a backoff policy.
- Added `FutureExt`: extension methods on futures.
- Added `next_frame`, `on_idle`, `run_in_phase`: hop a task to a chosen frame phase.
- Added `run_until`, `run_until_stalled`: drive Venus without an event loop, for tests and tools.

### Other

- Added `aimer_time`: a crate of time utilities, used throughout the framework.
- Added `aimer::assets` and `aimer::declare_assets!`: bundle and declare assets in your app. `BundledAssets` is now a trait.
- Added `aimer::thread_local`: backed by the new TLS crate, which solves the TLS overflow on Android. The whole workspace now uses it.

## Fixes

- Modals no longer leak events to non-modal children, and `Floating` now isolates its events.
- Providers can now reach a `Modal`.
- Fixed the glitch frame when `ExpandTransition` returns, and its blur affecting nearby items.
- `ExpandTransition` now always shows its background.
- Fixed a 1–2 frame miss on iOS Metal.
- Fixed a delay when touching the screen edge.
- Fixed a `SIGTERM` caused by `thread_local` at exit.
- Fixed `Drawable` on `BackingLayer`.
- Linux: fixed OpenGL rendering (new `CUPID_RENDER_BACKEND` override), multi-window bugs on OpenGL, and the parent window closing when a child window closes.
- Fixed rendering on WebGPU and a shader error on Windows.
- Fixed compile errors on `wasm32`, a race in a test, and scroll tests on non-macOS.

## Improvement

- Scrolling feels better on Linux.
- Paused video costs nothing per frame.
- Faster gradients.
- Faster `aimer::thread_local`.
- Optimized the Venus runtime.
- Optimized animation performance.
- Larger Markdown cache capacity.
- Windows: shaders can now be pre-compiled.
- The debug overlay shows more accurate information.
- The `Element` family is now documented.

## Changes

- **Breaking:** the v2 draw commands are now the framework's only drawing API. The `Drawable` paint hooks were renamed, and `update_retained` overrides that only repeated `update` were dropped.
- Graphic backends moved into `graphic/backends/`, and the `window` crate moved from `host/` to `native/`.
- Removed the experimental feature flag.
- Removed the old `jaime` app from the repo.
- Added the `polymorphism` experiment crate.
- The Android manifest in `jaime` now uses the new format.
- The Apple Xcode projects now link AVFoundation and CoreMedia.
