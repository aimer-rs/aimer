# Lottie sample animations

## `FingerprintScan.json`

Original work of the Aimer project, under the same terms as the repository
(MIT OR Apache-2.0). It is a fingerprint scan drawn from concentric arcs: each
ring draws on with a trim path, the strokes turn green when the scan matches,
and the whole animation fades out so that it can loop.

## Everything else

The other `.json` files in this directory are test animations from the Lottie
for Android project, exported from After Effects with Bodymovin:

- Source: <https://github.com/airbnb/lottie-android>, path
  `snapshot-tests/src/main/assets/Tests/`
- License: Apache License 2.0 (<https://www.apache.org/licenses/LICENSE-2.0>)

They are unmodified.
